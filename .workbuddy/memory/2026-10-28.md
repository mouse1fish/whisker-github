## 自举第 2/3 步彻底打通：elif 双 tAdvance 根因修复（本会话核心成果）

- **根因**：wkcc.wk 的 parseIf 中，elif 递归前多余 `tAdvance()` + 递归 parseIf 入口 `tAdvance()` 双吃，把 elif 条件首 token（如 tIsPunc）吞掉，条件退化为 `( 实参 )` 括号表达式 → 恒真（字符串）或恒假（0==K_IDENT）。共损坏 10 处 elif 链非首条件（parseActor 790/795、parseField 864、parseFunc 993、parseParamsOpt 1095、parseDeclOrAssign 1292、for 区间 1181、parseIf 1266、prescanFuncs 755 等）。
- **为何 verify_cp 21/21 一直全绿**：verify_cp 测的是 whiskerc（手写 Python parser，无双吃）；wkcc.wk 的 parseIf 只在自举链中执行。且 min_r/min_p 等"假阴性"复现因首条件为真屏蔽了恒真 elif。终极鉴别用例 min_t（首条件为假 + elif 调用条件 + else）：错误输出 22，修复后 33。
- **修复**：删除 elif 递归前的 tAdvance()，递归 parseIf 入口统一吃关键字（else-if 路径原本正确未动）。
